## What works, what does not yet

### THE VOID SPACE

A full-stack wallpaper-sharing platform that I built and deployed.

It includes:

- Node.js server and REST APIs
- User authentication and sessions
- Creator profiles and workflows
- Wallpaper CRUD operations
- Search, filtering and pagination
- Admin approval/moderation workflow
- PostgreSQL/Supabase database
- Supabase Storage
- Image validation and processing with Sharp
- Thumbnail, preview and WebP variants
- Security controls including origin/CSRF validation and input validation
- Deployment and production media delivery

Live application:
https://thevoidspace.online

Repository:
