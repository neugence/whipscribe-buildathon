# Shabaz Ansari

Frontend-focused developer building and shipping full-stack web applications and interactive web experiences with React, Next.js, TypeScript and Node.js.

## What I have built

### JobBoardMVP — proudest work
GitHub: https://github.com/Kise07/jobBoardMvp
Live: https://job-board-mvp-f4n8.vercel.app/

A full-stack job discovery platform that collects junior software roles from Hacker News "Who's Hiring?", filters them and presents them through a production web application.

Built with Next.js, React, TypeScript, Node.js, Express and Redis. I added scheduled data collection, Redis caching with a 24-hour TTL, rate limiting, CORS handling and separate production deployments.

### Minimal Portfolio
GitHub: https://github.com/Kise07/Minimal-Portfolio
Live: https://minimal-portfolio-beta-mocha.vercel.app/

An interactive frontend portfolio and UI experimentation space built with Next.js, React, TypeScript, Tailwind CSS and Motion.

It contains reusable interactive prototypes covering motion, transitions, magnetic interactions, 3D transforms and responsive UI.

### Link-in-Bio
GitHub: https://github.com/Kise07/link-in-bio
Live: https://link-in-bio-one-peach.vercel.app/

A lightweight link-in-bio web experience built with HTML, CSS and JavaScript, with interactive visual effects.
