Left: the current design from ../after/. Right: the next pass, live in a frame at the same width; you can tap and type in it. All screens · Notes

Reader at 320 pxmerged

One header row instead of two. Paragraphs instead of fragments, left-aligned, one timestamp each. The Keep reading bar and the player are one 64 px dock (was about 170 px), so the reading area grows by about 90 px.

Reader at 390 pxmerged

Same changes at 390. Export sits next to More in the header, so the tab row has room at every width.

Preview boundaryremoved

The inline end note is kept; the dock's Keep reading button hides once the note is on screen, so the offer is made once, not twice.

Keyboard upnew

With the search keyboard open, the dock goes away and the search field and results stay at the top. (The grey block stands in for the phone's keyboard.)

Searchkept

Kept as it was: count, up/down, close. Only the bottom stack is lighter, so more results fit.

Download, now one sheet patternmerged

Copy joins Download in one “Copy or download” sheet. The four everyday formats are shown; subtitles, Drive and summary sit under More formats. Same sheet component as More, sign-up and rename.

More menuremoved

Nine items become four: Rename, File details, Quiz me, then Delete after a gap. Home, Copy, Timestamps and Sign in are gone because each is already on screen.

Reading settingsmerged

No separate panel: text size and timestamps are a View row at the top of the same sheet.

Text selectionchanged

A bottom bar instead of a popover over the next line: Copy (with the timestamp), Share quote (a link to that second), Play from here.

Keep reading, then sign-upmerged

The same bottom sheet as every other panel, and it says you land back on the same line.

Load failurechanged

Plain words, not “HTTP 503”. Tabs, search and export are gone because they cannot work here.

Not on this accountchanged

No title stuck on “Loading…”, no dead tabs. Says who can open it and what to do. Also shows the wording for a deleted recording (today it says “transcript still ready”, #156).

Processingnew

There was no screen for this. Progress in steps, time left, what comes next, and whether it is safe to close the page.

Four speakers at 320 pxnew

A name chip with a colour dot starts each turn; the text keeps the full width. Tap a name to rename it everywhere.

Desktop at 1280 pxkept

The layout is kept. Shared fixes only: paragraphs by speaker, one Copy or download button, the full title, a labelled Study mode button, and no “QUEUED” on finished files.
