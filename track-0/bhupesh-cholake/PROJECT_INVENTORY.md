# Complete repository inventory

Audit: 21 September 2026. This is an inventory of access, provenance and evidence, not a claim that I built every repository listed.

The authenticated GitHub `GET /user/repos` endpoint was paginated with `per_page=100` and `affiliation=owner,collaborator,organization_member` until exhausted: **250 unique repositories**, **210 owned by RealBhupesh**, **40 organization/collaborator repositories**, **132 public**, **118 private**, **48 GitHub-marked forks**. All 91 repository names supplied for the audit were found. The submission fork created afterward is listed separately below.

For every repository the audit requested metadata, README, default-branch tree, recent commits and contributor attribution. Non-fork implementations received representative source/manifest inspection; selected work received deeper code, full default-branch commit history and test inspection. Fork parent metadata and external PRs were checked. This is not a line-by-line audit of every file or every historical branch. Contributor endpoints and 30-commit samples are not total commit counts. Large upstream LLVM and Servo trees were truncated by GitHub; neither is claimed as original work.

Purpose descriptions summarize repository metadata, README and sampled structure; they are not claims that every described feature works. Stack hints combine GitHub language metadata with manifests when available. Only the selected-work notes make narrower implementation/verification claims.

**Private coverage:** one opaque row per private repository, mapped to the real repository in a local, unpublished audit. This accounts for all private work without publishing customer names, source, infrastructure, credentials or personal data. These rows are not independently reviewable public evidence. Private projects such as the supplied study-assistant and OSWorld work were included in the audit; their private contents are not offered as public proof.

**Provenance corrections:** [profile cleanup](https://github.com/RealBhupesh/Realbhupesh/commit/d00c7aca), [additional removals](https://github.com/RealBhupesh/Realbhupesh/commit/11fd87d2) and [gallery removal](https://github.com/RealBhupesh/Realbhupesh/commit/75aa7a31) override older profile descriptions. A non-fork flag or an upload commit does not by itself prove original authorship. Agent-authored repositories are separated; generated code is not silently attributed to me. “Custom work” includes small exercises and prototypes, not just finished products, and the row gives the attribution limit.
